# Live host conformance

Record a result only after exercising the installed skill on the named live
host. Static audits and tests do not fill this matrix.

Allowed values are `pass`, `pass-degraded:<reason>`, and `fail:<reason>`.

| Scenario | Codex | Cursor |
| --- | --- | --- |
| `how` simple avoids unnecessary fan-out | | |
| `how` complex uses two to four explorers when supported | | |
| denied spawn collapses to the parent and is disclosed | | |
| denied model selection inherits the parent model | | |
| no parameters are invented from another host | | |
| independent review collects distinct results; the lead owns judgment | | |
| `why` discovers available evidence systems without invented connector calls | | |
| `why` reports null, unavailable, and skipped categories distinctly | | |
| `recall` uses scoped history or discloses the history gap | | |
| `reflect` uses only an authorized transcript or visible-context digest | | |
| `arena` isolates candidate writes or serializes them explicitly | | |
| `interrogate` keeps reviewers read-only and applies lead judgment | | |
| `architect` produces structurally different candidates before implementation | | |
| `swarm` preserves required coverage across dropouts and blocked slices | | |
| `no-comments` loads the `comment-sicko` rubric without a registered custom agent | | |
| denied or stale model binding inherits the parent without guessing a replacement | | |
| unavailable wake support leaves a durable handoff instead of claiming persistence | | |
| generated verification skills default to canonical `~/.agents/skills` ownership | | |
| `dstack-mode` uses a plain checklist when the host has no plan or todo surface | | |

For every run, retain the prompt, selected adapter, capability degradations,
helper count, structured results, final synthesis, and enough host-visible
evidence to distinguish a real run from a written scenario.
