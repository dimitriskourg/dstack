# Workflows

The workflow skills remain independently usable. `how`, `why`, `architect`, `arena`, `interrogate`, `swarm`, `reflect`, and the retained `dstack-mode` playbooks use native subagents without a capability matrix. Required fan-out uses bounded waves. Repository writers serialize; parallel workers are read-only or write independent artifacts outside the repository.

Use `control-ui` for browser or desktop UI evidence, `control-cli` for CLI and TUI evidence, and `deslop` for code cleanup. Static validation does not replace proof on the real surface.

See [Supported scope](06-supported-scope.md) for the retained playbooks and intentional exclusions.
