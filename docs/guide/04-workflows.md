# Workflows

The workflow skills remain independently usable. `how`, `why`, `architect`, `arena`, `interrogate`, `swarm`, `reflect`, and the `dstack-mode` playbooks use native subagents without a capability matrix.

Use `control-ui` for browser or desktop UI evidence, `control-cli` for CLI and TUI evidence, and `deslop` for code cleanup. Static validation does not replace proof on the real surface.
