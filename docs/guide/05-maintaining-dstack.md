# Maintaining upstream alignment

Read [Supported scope](06-supported-scope.md) and [DIFFERENCES.md](../../DIFFERENCES.md). Record exact pstack revisions, inventory source artifacts, and explain every retained or excluded difference. Port only supported material. Copy retained upstream skills first, then apply the smallest harness-neutral and team-required transformations.

Run the portability audit, unit tests, JSON validation, and Skill Creator validation for each changed skill. Follow with live harness checks for any behavior claim involving subagents, model selection, transcripts, UI, or long-running work.
